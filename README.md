# 🩺 Diaglo AI

Diaglo AI is a smart health app built to make managing diabetes simple. It brings together daily glucose logging, meal tracking for local Pakistani foods, and personalized advice powered by AI.

---

## What It Does

* **Account Creation:** Safe signup and login so every user's data stays private.
* **Personal Profile:** Tracks age, weight, height, BMI, and diabetes type.
* **Pakistani Meal Tracking:** Includes a menu of 30+ local meals with instant estimated calorie counts.
* **AI Daily Advice:** Uses Llama 3.3 to read your glucose levels and lifestyle details to give daily health tips.
* **7-Day Trend Graph:** Interactive charts showing your weekly glucose patterns and safe targets.

---

## Tech Stack

* **Frontend:** React (TypeScript), Vite, Tailwind CSS
* **Charts:** Recharts
* **Backend & Database:** Supabase (PostgreSQL)
* **AI Model:** Meta Llama 3.3 70B Instruct
* **Hosting:** Vercel
